# 星迹 Orrery

手势交互式 3D 太阳系探索应用，支持 Windows 桌面运行。

## 下载体验

**[下载 Windows 安装包](https://github.com/u-window/orrery-download/releases/latest/download/Orrery-Setup-1.0.0.exe)**

[查看版本与安装包列表](https://github.com/u-window/orrery-download/releases/latest)

下载 `.exe` 文件后运行安装。使用手势控制需要摄像头，并允许应用访问摄像头。

## 项目特点

- 手势导航、目标定位与跟随，兼容鼠标键盘操作。
- 太阳系三维漫游、天体运动、昼夜光影与时间调节。
- 国际空间站和深空探测器模型展示。
- 近光速飞行及相对论现象的探索性可视化。
- 基于 Three.js 与 Electron 构建，使用 NASA、USGS 等来源的科学影像。

部分轨道、显示尺度与视觉效果采用交互展示所需的简化，相对论视觉仍在完善。

本仓库用于分发体验版安装包。当前版本来自 2026-06-25 的本地构建。
